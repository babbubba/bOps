# V1.3-J — TLS and certificate diagnostics

Status: **implemented locally; awaiting CI Windows/Linux evidence**
Recommended model effort: **medio**
Repository: `bOps`
Depends on: V1.3-I complete

## Outcome
Add certificate expiry/trust and live TLS handshake evidence. No private keys, certificate install/remove or credential-bearing generic client.

## Package layout
Create cross-platform `bOps.Packages.Security` using BCL cryptography/network APIs.

## network.tls_probe — Read
Parameters: host, port 1–65535, optional sniHost, timeoutMilliseconds default 5000/max 15000, minTls=system|tls12|tls13.
Flow: resolve -> TCP connect -> SslStream handshake -> capture validation result; send no application data.
Output: `host,resolvedAddress,port,tcpConnectMs,tlsHandshakeMs,protocol,cipherSuite,alpn,certificate,chainValid,policyErrors,chainStatuses,complete`.
Certificate summary: subject, issuer, thumbprint, serialNumber, validity, daysRemaining, DNS SANs (max 100), key algorithm/size, signature algorithm.
A trust failure is successful diagnostic evidence with chainValid:false; inability to connect/handshake is Tool Failure.

## certificate.list — Read
Parameters location=currentUser|localMachine, store=my|root|ca, optional expiringWithinDays, limit default 200/max 2000.
Use X509Store. Public metadata only: thumbprint, subject, issuer, validity, hasPrivateKey boolean, EKUs/key usages, SAN summary. Never export key/PFX.

## certificate.inspect — Read
Parameters thumbprint/location/store. Return one certificate + X509Chain build result. Default revocationMode none; optional online only if bounded by tool timeout and documented as network activity.

## Explicit exclusion
No certificate.pem.inspect/path parameter here: that would bypass FilesystemPathPolicy. Any future certificate-file reader belongs under a filesystem-authorized design.

## Validation
In-process TLS test server for trusted/self-signed/expired/not-yet-valid/wrong-host certs; TLS1.2/1.3 capability-gated; test-owned temporary user certificate store; assert no private-key export APIs/output; bounded SAN/chain statuses.

## Definition of Done
bOps can diagnose open-port-but-TLS-fails, hostname/trust mismatch and expiring local certificates using public certificate evidence only.
