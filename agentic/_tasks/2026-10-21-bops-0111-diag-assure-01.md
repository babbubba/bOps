## Technical decisions and residual scope

The existing evidence contract has no typed diagnostic claim linked to rendered
prose. The reproduced 14/34 and 42/43 errors therefore remain semantic defects;
no numeric extraction or arbitrary category sums are added to production.
The test-only `NumericClaimFeasibilityTests` demonstrates a bounded proposal:
claims must cite task/step, query/time/source/category, opaque fact identity,
completeness and observed/lower-bound/total mode; addition requires a producer-
attested disjoint partition with common provenance. A wrong or absent identity
is not silently matched against another fact. Extraction coverage and a binding
between validated claims and rendered prose are prerequisites for DIAG-CLAIMS-01,
which is not implemented here. No new architectural decision is needed for this
read-only projection; a production claim/rendering contract still needs one.

Conservative reason refinements avoid false Checked results: unspecified
historical completeness and facts/values not visible in the bounded grounding
ledger remain Unchecked; typed inconclusive post-action verification remains Qualified.
Required steps whose tool is still undecided remain unexecuted limitations. Raw EvidenceRead ranges exist only in audit, so task-
only projection cannot certify full recovery of omitted output. The historical
reason name ObservationShortenedNotRead expressly means coverage not established.

Archive corpus fixture provenance: `Fixtures/diagnostic-assurance-metadata.json`
contains structural metadata from the 12 available specified archived states and
PRE-6 Qwen/KD, with source SHA-256 digests. All expectations were set to Qualified
before running the projection, based on observed partial/unavailable/shortened
metadata, not on model prose. Output, observations, goals, arguments, provider
payloads, paths and opaque fact names are replaced; facts preserve typed shape,
identity relationships and bounded-value visibility. No original payload is kept.
RV-01 T10 actually executed operational tools as well as Knowledge: it is correctly
Qualified; the separate synthetic Knowledge-only case is NotApplicable.

Production fixes: bounded dump scalar clipping now sets Partial/output-truncated;
DumpChk has an independent typed preflight result; processName is identified as
current context rather than cause; optional grounding skips at exactly the token
ceiling without changing completion. No additional inference call or budget raise.
No real-model token/latency A/B campaign was run; assurance uses zero inference
calls and the boundary fix avoids one optional call only in the exact-cap case.
