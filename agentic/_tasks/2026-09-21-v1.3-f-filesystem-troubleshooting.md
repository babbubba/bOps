# V1.3-F — filesystem troubleshooting helpers

Status: **in progress (2026-09-22)**

## Outcome
Add safe log/content/permissions/locking diagnostics plus single-file copy and mkdir, always through existing deny-by-default FilesystemPathPolicy.

## Tools
### fs.grep — Read
Parameters: path, pattern, recursive=false, regex=false, caseSensitive=true, maxMatches default 200/max 2000, maxOutputBytes default 32768/max 131072.
Stream line-by-line; do not follow symlinks/reparse points. Regex uses compiled .NET Regex with per-match timeout (default 250 ms, max 1 s). Return file,lineNumber,boundedLine; cap one line to 2048 UTF-8 bytes. Skip probable binary files via small bounded heuristic.

### fs.tail — Read
Parameters path, lines default 100/max 5000, maxBytes default 65536/max 1 MiB.
Read backwards from a regular file; no follow/stream. UTF-8/BOM support; unsupported/binary encoding reported explicitly.

### fs.permissions — Read
Parameter path. JSON: `path,exists,type,owner,group,unixMode,aclEntries,readOnly,source,complete`.
Windows uses System.Security.AccessControl; Linux uses File.GetUnixFileMode + stat owner/group resolution. Max 200 ACL rows. Do not claim effective authorization for arbitrary users.

### fs.locks — Read
Parameter path; limit default 100/max 1000.
Rows `pid,processName,user,accessKind,source`.
Windows uses Restart Manager APIs for the exact canonical file. Linux scans visible `/proc/<pid>/fd` and optionally correlates `/proc/locks`, with hard process/FD ceilings. Empty result + complete:false when visibility was restricted.

### fs.copy — Medium
Single regular file only. Parameters source,destination. Source read-allowed, destination write-allowed, both re-resolved immediately before operation. Destination must not exist. Config `Filesystem:Operations:MaxCopyBytes` default 1 GiB/hard max 10 GiB.
Add Read `fs.copy.verify` accepting source+destination and comparing existence,length,SHA-256. Copy via temporary sibling then rename when supported; clean only temp created by this invocation.

### fs.mkdir — Low
Parameter path. Write policy required. Idempotent if directory already exists; fail if a non-directory exists. Verify via fs.stat.

## Validation
S11 traversal/symlink/TOCTOU tests; grep regex timeout/binary/huge-line; tail CRLF/LF/BOM/large file; real Windows ACL/Linux mode; real lock holder; copy no-overwrite/limit/temp-cleanup/hash verification/cancellation; mkdir idempotency.

## Definition of Done
