## Outcome

Complete the audit trail of a delegated objective (ADR-0030 section 8).

## Checklist

- [x] Failing tests first: every event of a delegated run carries the correlation block; non-delegated runs are unchanged. V1.2-C2 already stamps it on every event the runner writes for a delegated role (tool call, policy decision, approval, model call, skill run) through one write helper, so what is left here is the orchestrator's own events and the read surfaces.
- [x] Emit the new delegation events for every transition, including denial, rejection, cancellation and reconciliation. D already writes the requested, envelope (granted per role at its start, and every denial), role started, role completed, human plan decision (`PlanDecided`, with the approver as the event's actor and the plan hash) and terminal events, all correlated; what is left is cancellation, budget consumption, the journal and reconciliation events.
- [x] Envelope contents are audited as a hash plus reduced dimensions; arguments and output keep existing redaction (S6) and stay out of telemetry.
- [x] `bops audit verify` still validates the chain across old and new events.

## Definition of Done

- [x] The whole delegation chain and evidence provenance can be reconstructed from the local audit log.
- [x] No secret or tool output reaches telemetry.

## Interpretations made in H

None changes an ADR.

1. **Ids, not content.** The evidence a role gathered is audited by id only. What it says stays in the stored run and never enters
   the log, so no redaction question arises.
2. **Whose evidence it is.** A role lists the evidence whose provenance names it. Evidence it received from an earlier role, such
   as the Discovery evidence a Diagnostic report carries forward, is listed under the role that gathered it.
3. **No separate event for provenance.** It rides on `RoleCompleted`, which already carries the acting agent, the status and the
   consumption, so a reader gets a role's whole outcome from one event.
4. **A role interrupted by a crash lists none.** Its report was never stored, so nothing is claimed for it; the restarted role
   lists what it gathers.
5. **Telemetry gains nothing.** The delegated run adds no activity or tag of its own; the test only proves that what exists
   carries no output or argument. Adding delegation ids to telemetry, if wanted, would be a separate decision on cardinality.
