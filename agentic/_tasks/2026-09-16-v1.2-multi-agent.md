# V1.2 — in-process multi-agent orchestration

Status: **future; do not start before V1.1-H closes**
Recommended model effort: **molto alto**
Repository: `bOps`
Depends on: released V1.1 Skill/Capability execution model

## Outcome

Delegate one objective among logical specialized agents in one process with explicit identity,
strictly reduced privileges, bounded resources, persistence and complete audit correlation.

## ADR and contracts

- [ ] Define agent identity, role, allowed capability/target/risk set, budgets, deadlines and parent.
- [ ] Define delegation as intersection/reduction of the caller's authority; an empty intersection
      is a denial, never a fallback to defaults.
- [ ] Define deterministic sequential orchestration first; parallel execution is excluded until a
      later conflict/blast-radius ADR.
- [ ] Define cancellation propagation, cycle/depth detection, idempotency and partial resume.
- [ ] Define independent verifier identity and prohibit self-approval/self-verification where policy
      requires separation of duties.
- [ ] Keep contracts product-neutral and dependency-free in `bOps.Abstractions`.

## Test-first implementation

- [ ] Add fake-agent/model tests for happy path, malformed delegation, privilege escalation, cycles,
      exhausted budget, timeout, cancellation and replay.
- [ ] Implement Discovery, Diagnostic, Remediation and Verification as roles/capability profiles,
      not hard-coded product agents in the core.
- [ ] Persist parent/child execution, delegated context, budget consumption and correlation IDs.
- [ ] Reuse Skill, policy, approval, entitlement hook, execution and verification paths unchanged.
- [ ] Audit delegation reason, effective authority, evidence provenance and terminal outcome locally.
- [ ] Resume safely without repeating completed side effects; fail closed when prior state is
      ambiguous.

## Validation

- [ ] Prove a child cannot broaden target, capability, risk, environment or maintenance window.
- [ ] Prove no role approves its own action and Verification remains independent.
- [ ] Prove budget/deadline/cancellation across nested work.
- [ ] Crash/restart tests cover every durable state transition.
- [ ] Release build, full non-live suite and Windows/Linux CI are green.
- [ ] Document the model and explicit absence of microservice/parallel guarantees.

## Definition of Done

- [ ] A complete objective crosses distinct roles with reduced privileges and correlated evidence.
- [ ] Delegation, persistence, resume and independent verification are deterministic and audited.
- [ ] No later remote/Control Plane behavior is pulled into V1.2.
