## Tools
### identity.current — Read
JSON: `user,uidOrSid,elevated,serviceAccount,groups,groupCount,groupsTruncated,authenticationType`.
`serviceAccount` is nullable when a platform cannot classify the effective identity from reliable
evidence. Supplementary groups are requested with `limit` (default 100, maximum 500).
Max groups default 100/hard 500. No tokens, environment or credentials.

### identity.users — Read
Optional includeDisabled=true, limit default 200/max 2000.
Rows: `name,id,enabled,local,home,shellOrProfile,lastLogonUtc,source`, where `enabled` is nullable.
No password hashes/shadow metadata. On Linux, do not infer disabled state from shell/profile; return `enabled:null` when the permitted sources cannot establish the state. With `includeDisabled=false`, exclude only users positively known disabled.

### identity.groups — Read
Optional limit. Rows `name,id,memberCount,members`, max 100 members/group with truncation. No recursive nested expansion.

### identity.sessions — Read
Rows: `sessionId,user,state,loginTimeUtc,remote,clientAddress,ttyOrStation,source`.

`identity.users`, `identity.groups`, and `identity.sessions` include top-level `complete` and
`source` evidence for each execution. Local Linux passwd/group sources explicitly remain incomplete
because directory identities cannot be established from those files alone.

## Windows
- WindowsIdentity.GetCurrent / WindowsPrincipal.
- NetAPI32 NetUserEnum, NetLocalGroupEnum, NetLocalGroupGetMembers.
- WTS APIs for sessions.
- No Active Directory domain crawl.

## Linux
- getuid/geteuid + /etc/passwd + /etc/group; never /etc/shadow.
- sessions via fixed loginctl list/show when available; bounded local fallback only.
- network directory identities not represented by local files => source incomplete.

## system.time — Read
Return `utcNow,localNow,timeZoneId,utcOffsetMinutes,dst,clockSource,ntpConfigured,ntpSynchronized,timeServiceStatus,source,complete`.
Windows: DateTimeOffset/TimeZoneInfo, Windows Time service, documented W32Time registry config. Do not parse localized w32tm prose.
Linux: fixed `timedatectl show` explicit properties; fallback to BCL/time service evidence.

## system.reboot_pending — Read
Return `pending,reasons,source,complete`.
Windows sources: CBS RebootPending, Windows Update RebootRequired, PendingFileRenameOperations, pending computer rename/domain state when readable.
Linux: /var/run/reboot-required and distribution-specific well-defined markers. Unsupported distro markers => complete:false, not false certainty.

## Validation
Conformance/bounds; disabled users/group truncation; no credential material; time-zone-safe assertions; reboot detectors with isolated fixtures + real smoke.
