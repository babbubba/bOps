# V1.2-M — integration and release gate

Status: **planned**
Recommended model effort: **alto**
Repository: `bOps`
Depends on: V1.2-L complete
Governing ADR: `docs/architecture/adr/0030-privilege-reducing-multi-agent-delegation.md`

## Outcome

Prove V1.2 end to end on both platforms and record the gate, as V1.1-H did.

## Checklist

- [ ] Release build with zero warnings, full non-live suite, Angular production build and tests.
- [ ] End-to-end objective on Windows and Linux with real tools: discovery, diagnosis, human approval, remediation, independent verification, plus a crash and resume scenario.
- [ ] Confirm no removed or changed member of the 1.0 surface and that the SDK packs as intended. Make this a
      permanent snapshot test of the 1.0 public surface (members, signatures and enum values) rather than a
      manual dump: the V1.2-B check found a renumbered enum that the V1.1-H name-based diff missed.
- [ ] Green Windows and Linux CI on `main`; tag and release only with explicit operator authorization.

## Definition of Done

- [ ] A complete objective crosses distinct roles with reduced privileges and correlated evidence.
- [ ] No later Control Plane behavior is pulled into V1.2.
