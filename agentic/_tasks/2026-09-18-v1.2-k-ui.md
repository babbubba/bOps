Status: **planned**

Repository: `bOps`
Depends on: V1.2-J complete

## Outcome

Let an operator follow and control a delegation from the dashboard (ADR-0030 section 9). V1.1-F was revised from medio to alto during implementation; revisit this effort if the same happens.

## Checklist

- [ ] Delegations list and detail: roles in order, reduced authority, evidence and findings, plan hash and approval prompt, verification verdict, journal and any ambiguity awaiting reconciliation.
- [ ] Reconcile and cancel actions visible only to the permitted role.
- [ ] Untrusted output rendered with the existing safe-text rules.
- [ ] Component and store tests plus the production build.

## Definition of Done

- [ ] The dashboard shows the whole delegation lifecycle and never exposes secrets.
