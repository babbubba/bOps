# V1.2-I — CLI surface

Status: **planned**
Recommended model effort: **medio**
Repository: `bOps`
Depends on: V1.2-H complete
Governing ADR: `docs/architecture/adr/0030-privilege-reducing-multi-agent-delegation.md`

## Outcome

Expose delegation to the operator from the CLI (ADR-0030 section 9).

## Checklist

- [ ] `bops delegate "<objective>"` and `bops delegate status|resume|cancel|reconcile <id>`; the existing `bops "<goal>"` keeps working unchanged.
- [ ] Composition root: build `PolicyRoleProfileSource` over the same loaded `PolicyConfig` the policy engine comes from (`LoadPolicyEngineAsync` returns only the engine today), and register it as the `IRoleProfileSource` with the `DelegationRunner` (V1.2-D). A broken `policy.yaml` is `AllForbidden` and has no profile, so a delegation start must end `Denied` on the `Profile` dimension; test that here.
- [ ] Human approval prompt: a console `IPlanApprovalProvider` (the SDK contract D added), showing the plan hash, the plan's steps, the findings and the reduced authority. The runtime refuses a decision that does not come from a human identity.
- [ ] Clear exit codes and messages for denied, cancelled, requires-reconciliation and completed states.
- [ ] Tests drive the real CLI against a fake model provider.

## Definition of Done

- [ ] An operator can start, approve, resume and reconcile a delegation from the terminal.
