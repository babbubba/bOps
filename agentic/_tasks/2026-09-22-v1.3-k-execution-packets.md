## K1 — shared System contract for updates/history/crashes/drivers

**Model:** Luna Low/Medium.

### Read first
- parent K task;
- existing `bOps.Packages.System.Core` result/argument/formatting patterns;
- System conformance suite.

### Implement in System.Core
- manifests;
- arguments/bounds;
- result DTOs/output formatting;
- shared enums/normalization helpers;
- conformance assertions.

No OS/package-manager calls in Core.

### Completeness
Every result that aggregates native sources must expose source/completeness/warnings so:
- stale local metadata is distinguishable from no updates;
- missing crash backend is not an empty-complete crash history;
- truncated driver/module scans are incomplete.

## K2 — Windows pending updates

**Model:** Luna Medium. Terra Medium only for isolated COM interop issues.

### Native recipe
Windows Update Agent COM via `Microsoft.Update.Session`/searcher.
No PowerShell, winget, install/download/accept-EULA mutation.

Use fixed search criteria owned by the package. Caller only supplies normalized `kind` and `limit`.

### Required evidence
Map id/title/current/available version where WUA exposes them; do not invent versions.
Map security/critical only from authoritative update categories/evidence.
Published time and reboot hint are nullable if source lacks them.

### Tests
Never install. Use safe COM abstraction/fixture parsing where needed plus real read-only smoke on
windows-latest if the service/API is available. Unavailable WUA is explicit incomplete evidence.

## K3 — Linux pending updates

**Model:** Luna Medium.

### Native recipe
Use exactly the distro family commands allowed by parent task:
- Debian/Ubuntu: fixed `apt-get --just-print upgrade` + local metadata parsing;
- Fedora/RHEL: fixed `dnf check-update --cacheonly`;
- SUSE: fixed `zypper --xmlout list-updates`.

No repo refresh and no shell. Never add caller-provided package names/options.

### Metadata age
Report cache/catalog age when a reliable local timestamp exists; otherwise null + warning, not a
fabricated age.

### Tests
Deterministic fixtures for:
- no updates;
- security update;
- held package;
- stale cache;
- command unavailable;
- non-zero exit conventions such as dnf's documented update-available code.

## K4 — update history Windows/Linux

**Model:** Luna Medium.

Windows:
- WUA history, bounded by sinceDays/limit.

Linux:
- local package-manager logs/history only;
- no network;
- no filesystem-wide search;
- known paths/backends only.

Normalize result success/failure/unknown honestly. Missing/rotated history implies incomplete, not no
history.

Tests use recorded/local fixtures and UTC-safe timestamps.

## K5 — Windows crash evidence

**Model:** Luna Medium.

Sources:
- bounded WER report metadata from known locations/APIs;
- Application Error/WER event metadata where required.

Never parse dump contents and never recursively scan arbitrary drives for dumps.

Normalize:
`timestampUtc,process,pid,kind,dumpPath,eventIdOrCrashId,summary,source`.

`dumpPath` is metadata only; do not read the dump through this tool.

Tests:
fixture WER metadata + real event smoke if available; bounds and permission/incomplete semantics.

## K6 — Linux crash evidence

**Model:** Luna Medium.

Preferred fixed direct `coredumpctl` bounded list/query where available.
No shell and no dump extraction.

Fallback only to explicitly known core-pattern metadata; never filesystem-wide dump discovery.

If coredump journal is unavailable/permission denied, return incomplete evidence.

Tests:
deterministic coredumpctl fixture + real smoke where available.

## K7 — drivers/modules Windows/Linux

**Model:** Luna Medium.

Windows:
- `EnumDeviceDrivers`;
- `GetDeviceDriverBaseName` / `GetDeviceDriverFileName`;
- bounded file version metadata.

Linux:
- `/proc/modules`;
- bounded `/sys/module` metadata lookups.

No load/unload/update operations.

Required tests:
- shape/order/bounds;
- disappearing module/driver race;
- inaccessible metadata degrades individual fields/completeness rather than failing unrelated rows.

## K8 — architecture/docs/CI gate

**Model:** Luna Low/Medium.

### Architecture assertions
No first-party tool added for:
- update install/download/remove;
- driver load/unload;
- dump-content read;
- arbitrary package manager invocation.

### Validation
Targeted System Core/Windows/Linux/Conformance + Architecture first.
Then once:
```bash
dotnet build bOps.slnx -c Release
dotnet test bOps.slnx -c Release --no-build --filter "Category!=LiveModel"
```

Record which distro-specific commands were fixture-tested vs exercised on CI.

### K Definition of Done
bOps can correlate pending/stale updates, recent package change, crash metadata and loaded
driver/module state without modifying host maintenance state or mistaking unavailable metadata for a
clean machine.
