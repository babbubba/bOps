## J2 — network.tls_probe

**Model:** Luna Medium. Sol Low may review the final diff; do not use Sol for implementation by default.

### Flow
1. validate host/port/sni/minTls/timeout;
2. DNS resolve using BCL;
3. bounded TCP connect;
4. `SslStream` handshake;
5. capture certificate/chain/validation evidence;
6. send no application data;
7. close.

### Trust semantics
Certificate trust/hostname failure is **successful diagnostic evidence**:
- tool succeeds;
- `chainValid:false`;
- policy/chain errors are returned.

TCP/connect/handshake inability that yields no usable TLS evidence is Tool Failure.

Do not globally disable validation. A callback may capture validation evidence, but the implementation
must not turn invalid chains into a claimed valid session.

### TLS versions
`minTls=system|tls12|tls13`.
Use BCL protocol controls only. No custom crypto.

### Bounds
- SAN max 100;
- chain statuses bounded;
- certificate text/subject fields bounded;
- timeout default 5000/max 15000.

### Tests
In-process TLS server/fixture:
- valid/trusted where test infrastructure can establish trust;
- self-signed/untrusted;
- hostname mismatch;
- expired;
- not-yet-valid;
- TLS1.2;
- TLS1.3 capability-gated;
- refused connection;
- handshake failure;
- timeout;
- SNI selection.

Tests must verify no application bytes are sent.

## J3 — certificate.list

**Model:** Luna Medium.

### Native recipe
Use `X509Store` only for:
- currentUser/localMachine;
- my/root/ca.

Read public metadata only:
thumbprint, subject, issuer, validity, hasPrivateKey boolean, EKUs/key usage, bounded SAN summary.

Do not call export APIs for private material.

### Filters
`expiringWithinDays` operates on UTC-safe validity comparison and never changes the store.

### Tests
Use a test-owned temporary user store where supported.
Assert:
- list bounds/order;
- expiration filter;
- private key presence is boolean only;
- output contains no private-key/PFX material.

## J4 — certificate.inspect and chain

**Model:** Luna Medium; optional Sol Low review after tests.

### Input
thumbprint + location + store.
Normalize thumbprint comparison case/spacing deterministically.

### Chain
Use `X509Chain`.
Default revocation mode: none.
Optional online revocation is allowed only if:
- parent contract exposes it;
- network activity is explicit;
- bounded by tool/runtime timeout;
- tests do not rely on public Internet.

Return chain evidence and statuses; no mutation.

### Not found
Return an explicit diagnostic not-found shape/failure consistent with the package's chosen contract;
do not silently return an empty certificate object.

## J5 — security review, docs and CI

**Implementation model:** Luna Low/Medium.
**Optional review:** Sol Low, narrow review only.

### Review checklist
- no validation bypass reported as success;
- SNI and hostname used correctly;
- no private key export APIs;
- no certificate-file path bypass of FilesystemPathPolicy;
- timeout/cancellation reaches DNS/connect/handshake as far as BCL permits;
- bounded SAN/chain/status output;
- no secret material in errors/logging.

### Architecture guard
Search/test for forbidden private-key export patterns in the new package/tests while allowing
legitimate test fixture certificate creation only in test projects.

### Validation
Targeted Security + Architecture tests, then one full Release build/non-live suite and both CI OSes.

### J Definition of Done
bOps distinguishes TCP failure, TLS handshake failure, trust failure, hostname mismatch, time validity
and local certificate expiry without sending application data or exposing private key material.
