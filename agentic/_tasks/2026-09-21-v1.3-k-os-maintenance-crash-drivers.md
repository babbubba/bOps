# V1.3-K — updates, crash evidence and driver/module inventory

Status: **future; starts only after V1.3-J**
Recommended model effort: **medio**
Repository: `bOps`
Depends on: V1.3-J complete

## Outcome
Add remaining read-only host-maintenance evidence: pending OS/package updates, update history, crash/coredump metadata and loaded drivers/modules. No update install/remove or driver mutation.

## Tools
### system.updates — Read
Optional kind=all|security|critical|other, limit default 200/max 2000.
Rows: `id,name,currentVersion,availableVersion,kind,rebootMayBeRequired,source,publishedUtc`, plus catalogAge/complete/warnings.

Windows: Windows Update Agent COM (Microsoft.Update.Session/searcher), fixed search criteria, bounded search time/results; no PowerShell/winget.
Linux:
- Debian/Ubuntu: fixed direct apt-get --just-print upgrade and package metadata parsing;
- RHEL/Fedora: fixed direct dnf check-update --cacheonly when available;
- SUSE: fixed direct zypper --xmlout list-updates.
Never refresh repos as hidden side effect. Report metadata/cache age.

### system.update_history — Read
Optional sinceDays default 30/max 365, limit default 200/max 2000.
Rows timestampUtc,id,name,version,result,source.
Windows WUA history. Linux local package-manager logs/history only.

### system.crashes — Read
Optional sinceMinutes default 1440/max 10080, limit default 100/max 1000.
Rows: `timestampUtc,process,pid,kind,dumpPath,eventIdOrCrashId,summary,source`.
Windows: bounded WER report metadata + Application Error/WER event metadata as needed; never full dump contents.
Linux: fixed coredumpctl bounded list when available; otherwise known core-pattern metadata only; never filesystem-wide dump scan.

### system.drivers — Read
Optional limit default 300/max 3000.
Rows: `name,pathOrModule,version,vendor,state,loaded,addressOrSize,source`.
Windows: EnumDeviceDrivers + GetDeviceDriverBaseName/FileName + bounded file version metadata.
Linux: /proc/modules + /sys/module metadata.
No load/unload operations.

## Relationships
system.reboot_pending remains V1.3-H. system.events is broad time-series evidence. system.crashes is a compact crash artifact index. system.apps is installed inventory; system.updates is pending-change inventory.

## Validation
WUA tests never install; package-manager parsers use deterministic fixtures for no/security/held/stale cases; history only local sources; crash parser fixtures plus test-owned artifacts; driver/module shape/bounds; architecture test proves no update/install/driver mutation tools.

## Definition of Done
bOps can establish pending known updates, recent package change, crash evidence and loaded driver/module state without changing the host.
