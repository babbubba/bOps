# V1.1-A — complete the Skill/Capability SDK

Status: **implemented and validated locally; Windows/Linux CI pending**
Recommended model effort: **molto alto**
Repository: `bOps`
Depends on: ADR-0023, ADR-0024 and the current green V1.1 baseline

## Outcome

Deliver the missing executable Skill boundary and prove it with one non-commercial OSS sample Skill
that uses the existing governed tool pipeline from evidence gathering through verified reporting.

## Scope guardrails

- No V1.2 agent identity, delegation or orchestration.
- No database/product name in core contracts and no commercial playbook.
- Skill logic is deterministic package code, not an extra model call.
- `IToolInvoker` exposes only Risk `Read` tools from the requesting package and still applies
  validation, policy, timeout, audit and output limits.
- ExecutionPlan steps continue through the ordinary policy/approval/verification path; there is no
  privileged Skill executor.
