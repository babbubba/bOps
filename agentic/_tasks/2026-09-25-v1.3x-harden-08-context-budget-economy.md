## Objective

A long troubleshooting session keeps a bounded prompt size and a bounded cost while the complete
evidence record stays persisted and retrievable. Budgets are safe by default.

## Confirmed defects addressed

- About 47 KB of each 58 KB request in task 88f97dda is the 100 tool schemas (≈ 11–12 K prompt tokens
  per call; 12,832–19,797 prompt tokens per call with few messages).
- Each observation is truncated to `MaxObservationCharacters=4000` independently, but history
  accumulates all of them; the replan prompt ("Steps taken so far") grows by up to 4,000 characters per
  step (9,283 characters at step 6).
- `MaxTotalTokens` defaults to `null`: no token/cost budget at all by default.
- No handling for context overflow.

## Source finding IDs

F-18, F-07 (budget defaults). Uses `ContextOverflow` from HARDEN-2 and attempts/cumulative tokens from
HARDEN-3.

## Scope

1. **Older-step compaction**: the model-facing history keeps the last K steps verbatim (configurable);
   older tool observations are replaced by a runtime-authored compact digest per step (tool, arguments,
   outcome, `FailureKind`, `Completeness`, first N characters) with an **evidence id** referencing the
   persisted step. The persisted `TaskState` and the audit remain complete — nothing is deleted.
2. **Replan digest**: `ReplanAsync` uses the compacted digest instead of re-sending every truncated
   observation.
3. **Evidence retrieval**: the model can ask for a compacted step's full observation through the
   runtime (a runtime-provided read of its own task evidence by evidence id — not a new operational
   tool and not a generic accessor), bounded by `MaxObservationCharacters`. If this cannot be designed
   without a new tool, stop and propose it in the ADR amendment.
4. **Context overflow**: on `ContextOverflow` the runtime compacts more aggressively once and retries
   once; a second overflow ends the attempt with a clear terminal reason.
5. **Default budgets**: set a documented default `Agent:MaxTotalTokens`, keep per-attempt `MaxSteps`
   and `Agent:MaxLifetimeSteps` from HARDEN-3, add an optional per-attempt duration budget; expose
   tokens used in the task view (from HARDEN-3).

## Out of scope

- Filtering which tools are offered to the model (deferred: relevance filtering of the tool view, plan
  §15).
- Plan/replan without native tools (done in HARDEN-1).
- Evidence-reasoning prompt (HARDEN-9).

## Architecture constraints

- Never destroy audit or persisted evidence; compaction affects only the model-facing context.
- Compaction text is runtime-authored and delimited; tool output stays data.
- The core names no package or tool.

## Likely components/files

`src/core/bOps.Runtime/AgentRunner.cs` (history building, `RebuildHistory`, `ReplanAsync`,
`DescribeStepsSoFar`), `AgentRunnerOptions.cs`, `src/core/bOps.Api/appsettings.json` (`Agent` section
defaults), `TaskStateView.cs`, runtime tests.

## ADR prerequisite

**ADR-0014 amendment** (replan digest, older-step compaction, evidence ids, overflow handling).
Accepted before implementation.

## Public contract impact

Additive configuration keys and defaults (`MaxTotalTokens` default value, compaction window, duration
budget); documented semantic change of defaults. No Abstractions change unless evidence retrieval
requires one (then ADR).

## Security implications

- Default token budget limits cost exposure from runaway sessions.
- Evidence retrieval must only read the current task's own persisted evidence.

## Dependency gates

HARDEN-3 complete. Executes after HARDEN-9 in the canonical order.

## Acceptance criteria

- [ ] E2E-13: a scripted 40-step session across ≥ 2 attempts keeps the prompt below a documented bound
      while every observation remains retrievable from the persisted task.
- [ ] Replan prompt size does not grow linearly with step count beyond the verbatim window.
- [ ] A simulated `ContextOverflow` triggers exactly one compaction retry.
- [ ] A task with default configuration ends `BudgetExceeded` when the default token budget is exhausted,
      and the budget is cumulative across attempts.

defaults; E2E-13 with a scripted fake model.

## Required platform evidence
