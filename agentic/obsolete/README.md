# Obsolete planning archive

Everything below this directory is historical, non-normative and excluded from normal coding-agent
bootstrap. **Do not derive scope, sequencing, acceptance criteria or implementation choices from
these files.** The active source of truth is:

- `agentic/_plans/2026-09-16-consolidated-roadmap.md` for roadmap, status and gates;
- `agentic/_tasks/` for executable work;
- `agentic/00-*.md` through `agentic/07-*.md` and accepted ADRs for binding rules.

An agent may read an archived file only when an active task explicitly asks for historical research.
If an archived statement conflicts with active material, the archived statement has no authority.

## Contents

- `plans/`: superseded project plans and plan snapshots.
- `specifications/`: migration inputs whose accepted requirements have already been normalized.
- `tasks/`: completed or superseded task snapshots that must not be resumed.

Files remain versioned to preserve provenance and decision history. They are ignored by agents, not
by Git.
