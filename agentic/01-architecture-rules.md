# Architecture rules — compatibility index

> **Non-normative compatibility index.** It contains no rule text and no authority. Binding rules live only in the five current contracts under [`docs/architecture/current/`](../docs/architecture/current/). The original full text is preserved unmodified in [`docs/architecture/archive/`](../docs/architecture/archive/) (provenance only; do not load it unless the operator asks for historical research).

This file used to hold the architecture rules A1–A13, B1–B10, C1–C9 and D. Source code, tests and old task packets still cite those identifiers, so each one is kept here as a pointer. **It is not read by the bootstrap and does not take part in precedence**: [`00-bootstrap.md`](00-bootstrap.md) defines the chain. A rule you need is the contract rule in the last column.

The "Former title" column is only the label of the historical identifier. If it and the contract differ, the contract is right.
