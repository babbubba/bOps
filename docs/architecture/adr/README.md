# ADR compatibility index

> **Non-normative compatibility index.** It contains no rule text and no authority. Binding rules live only in the five current contracts under [`docs/architecture/current/`](../current/). The original full text is preserved unmodified in [`docs/architecture/archive/`](../archive/) (provenance only; do not load it unless the operator asks for historical research).

The ADR Markdown files that used to live in this directory were retired by `BOPS-0121` (DOC-CONSOL-01, DOC-03) and are preserved unmodified in `docs/architecture/archive/legacy-adr-and-decisions-2026-10-22.zip`. This index keeps every historical `ADR-NNNN` identifier (and its former file name) resolvable. New architectural decisions are **not** recorded as ADRs: a structural change modifies a current contract and needs operator approval ([`agentic/00-bootstrap.md`](../../../agentic/00-bootstrap.md)).

Reading the last column: **`Cn-Rmm`** is a binding rule of a current contract; **Contract N pending (Dn)** is a non-binding section awaiting the operator decision Dn (D1, D4 and D5 are open); a path is a current technical reference; **historical only** means the text has no current counterpart by design. Status shown is the *decision* status; the seven Proposed ADRs (0050, 0053, 0054, 0055, 0056, 0058, 0059) were not promoted by the consolidation. Implementation status is recorded per rule in the contracts.
