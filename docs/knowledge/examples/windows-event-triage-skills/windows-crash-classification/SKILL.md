# Classificazione dei crash Windows

Prima di attribuire una causa, stabilisci di che tipo di evento si tratta. Tipi diversi hanno prove, conseguenze e cause diverse.

- `references/crash-taxonomy.md`: i sei tipi di evento e come riconoscerli dalle evidenze.
- `references/live-dump-vs-bugcheck.md`: un kernel live dump non e un BSOD e non riavvia il sistema.
- `references/unexpected-shutdown-and-restart.md`: arresti inattesi, riavvii, blocchi e interruzioni di alimentazione.
- `references/application-vs-system-crash.md`: crash di un processo contro crash del sistema.
